## Live Agent Simulation Rule
Agent movement is state-driven.

Examples:
- PRODUCT → DESIGN → STORE as a product moves through pipeline.
- CUSTOMER/FULFILLMENT respond to simulated customer/order events.
- ULTRON reacts to exceptions.
- SENTRY audits escalations.
- Council leaders physically move to Council when called.
- Tapping an agent should expose current task/state.

No random movement should be presented as real work once production integrations exist.

Task lifecycle:
Created → Assigned → Running → Awaiting Approval → Completed / Failed

Permission levels:
READ / DRAFT / EXECUTE / ADMIN

Approval modes:
AUTO / NOTIFY / APPROVAL / BLOCKED

## Trading Guardrails
- Max 1% risk per trade
- Max 3% daily loss
- No averaging down
- No gambling trades
- A+ setups preferred
- 3–5 trades/week preference
- Business cash must never automatically become trading collateral
